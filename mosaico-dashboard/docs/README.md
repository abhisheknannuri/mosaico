# Dashboard docs

| File | Purpose | Update when |
|---|---|---|
| `BACKLOG.md` | Ordered task list (scrum board). One task at a time. | Every task start/finish |
| `DEVLOG.md` | One line per finished task: what changed, anything surprising. | Every finished task |
| `decisions/` | Architecture Decision Records (ADRs), one file per decision, never rewritten, only superseded. Template: `0000-template.md`. | When a task makes a decision |
| `architecture.md` | Layers, import rules, API conventions, data flow (created in D-03). | When structure changes |

The overall product/strategy plan is `../../DASHBOARD_BUILD_PLAN.md` (repo root).
